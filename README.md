# Фото → PDF

Бесплатный конвертер фотографий в PDF прямо в браузере. Файлы никуда не загружаются.

- Сотни и тысячи фото за раз (JPG, PNG, WebP, GIF, BMP)
- Разбивка на части по 100/200/500 страниц или один файл
- A4 или размер фото, поля, качество, максимальный размер стороны
- Сортировка по имени и ручной порядок

Откройте `index.html` в браузере или через GitHub Pages.
